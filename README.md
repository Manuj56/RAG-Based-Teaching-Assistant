# RAG-Based Teaching Assistant 🤖📚

An AI-powered teaching assistant that helps students interact with their study materials using **Retrieval-Augmented Generation (RAG)**.

The system retrieves relevant information from uploaded documents and provides **context-aware and document-grounded answers** using an LLM.

## ✨ Features

- 📄 Ask questions from study materials
- 🔍 Semantic search using vector embeddings
- 🧠 Context-aware AI responses
- 📚 Document-based question answering
- ⚡ Reduced hallucinations through retrieved context

## 🛠️ Tech Stack

**Python | LangChain | Gemini | BGE-M3 | FAISS/ChromaDB**

## 🔄 RAG Pipeline

**Documents → Chunking → Embeddings → Vector Search → Context → LLM → Answer**

## 🎯 Purpose

Built to make learning more interactive by allowing students to **chat with their own study material** instead of manually searching through lengthy documents.
